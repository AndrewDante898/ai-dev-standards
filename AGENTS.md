# AI development standards

This repository stores reusable standards and skills. For website creation, frontend design or visual refinement, read `skills/design-polished-websites/SKILL.md` and its linked resources. Andrew prefers the AI to choose a suitable visual direction and tools automatically, respecting the project's existing branding and explicit requirements.

When maintaining this collection, keep source URLs, review dates and verification status. Do not convert unknown reel resources into claimed facts. Preserve portability and relative reference links. Changes here do not automatically update separately installed skills or other projects.

For web apps, APIs, production-readiness reviews or performance work, read `standards/traffic-readiness.md`. Assess all five checks (database queries, caching, image delivery, load testing and rate limiting), implement relevant improvements within the task's scope, and report measured evidence or explicitly unverified checks. Choose solutions for the current stack; do not add unnecessary services. Apply this alongside the design skill when both appearance and production behaviour are in scope.
